# MAX Chat (GREEN-API)

Простой веб-чат на React, работающий через GREEN-API (мессенджер MAX).

## Что умеет

- Авторизация по idInstance и apiTokenInstance
- Сохранение данных авторизации в localStorage
- Список чатов
- Создание чата по номеру телефона
- Отправка и получение текстовых сообщений
- Разделение своих и входящих сообщений

## Стек

- React 19 (Vite)
- SCSS
- GREEN-API HTTP API

## Как запустить

1. Клонируй репозиторий
2. Установи зависимости:

```bash
npm install
npm run dev
```

## Структура проекта

```
src/
├── api/              # запросы к GREEN-API
├── components/       # UI компоненты
├── hooks/            # кастомные хуки
├── utils/            # вспомогательные функции
├── config.js         # конфигурация
├── App.jsx
├── Chats.jsx         # основной контейнер
└── main.jsx
```

## Использование

После запуска необходимо ввести:

- idInstance
- apiTokenInstance

После авторизации можно выбрать чат и обмениваться сообщениями через Green API.
В Green API обязательно зарегистрироваться и взять свои данные.
